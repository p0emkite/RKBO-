# RKBO 통산 제작기 (v1 베타)

기존 RKBO 카드 갤러리 저장소의 /career-maker/ 하위 웹앱입니다. 저장소 main 브랜치에 병합 후 https://p0emkite.github.io/RKBO-/career-maker/ 에서 열 수 있습니다.

## 현재 구현 범위

- HHRecord.zip 내 Results/Players/p_*.htm 파일 전체 파싱: 타자/투수, 선수 ID, 선수명, 등번호, 현재 소속 구단, ML 시즌별 성적, LAST 3, ML Career
- 최초 가져오기 이후 시즌 ZIP을 다시 넣으면 **선수 ID + 시즌**을 키로 업데이트(중복 누적 방지)
- 최근 시즌이 더 최신인 자료에서만 현재 구단/등번호/ML Career/LAST 3 요약 갱신
- 최신 소속 구단별 선수 검색 및 선택
- 기존 RKBO 저장소의 logos/{TEAM}.webp 재사용
- 선택된 최신 구단에 맞는 대표 색상, 시즌 행별 확인된 구단 색상
- 업로드한 **투명 PNG** 선수 사진을 브라우저 안에서 배치하고 X/Y/확대 조정
- 참여한 ML 시즌 개수에 따라 표 자동 확대, Canvas 기반 PNG 저장
- FA 플래그와 A/B/C **수동 등급 설정** 및 A등급 노란색 강조
- IndexedDB 브라우저 저장, DB JSON 내보내기/불러오기

## 기본 사용법

1. 사이트에서 2010 등 기존 HHRecord.zip 파일을 한 번 불러옵니다. (첨부 예시는 535명, ML 시즌 행 1,948개, ML Career와 Last 3 각 535개)
2. 최신 소속 구단, 선수 순으로 선택합니다.
3. 선수 PNG를 업로드하고 필요할 때 사진 위치/크기를 조절합니다.
4. PNG 다운로드를 누릅니다.
5. 다음 시즌 끝에 그 시즌 HHRecord.zip을 다시 업로드합니다. 새 시즌 기록이 DB에 반영되며 기존 시즌 중복은 생기지 않습니다.
6. 브라우저 초기화나 기기 변경에 대비해 DB JSON 백업을 보관합니다.

## 중요 제한 사항

- **기존 Google Sheet의 실제 수식·조건부 서식은 아직 검증하지 못했습니다.** 연결 권한 없이 공유 링크의 내부 셀을 읽을 수 없어 현 디자인과 FA 자동 등급 산식을 복제했다고 주장하지 않습니다.
- **FA 등급은 임시 수동 입력**입니다. 원본 수식 확인 후 자동 산정할 예정입니다.
- 사용자 지정 최종 PNG 규격/테두리/좌표는 규격 이미지 업로드 후 조정합니다.
- HHRecord의 과거 시즌 일부는 해당 시즌의 소속 구단 정보가 표기되지 않습니다. 이를 최신 구단으로 소급하지 않고 '—'로 표시합니다. 예전 시즌 ZIP을 추가하면 당시 현재 팀 태그를 이용해 이력 보강 가능합니다.
- 선수 ID는 **한 리그의 HHRecord 안에서만 안정적**이라는 전제입니다. 서로 다른 리그 유니버스의 ZIP을 섞지 마세요.
- IndexedDB는 사이트 주소+브라우저에 속하며 GitHub에 자동 업로드되지 않습니다. 공개 저장소에 실제 선수 DB나 개인 사진을 임의로 푸시하지 않습니다.
- 브라우저에서 처리되며 HHRecord 원본 ZIP은 서버로 보내지지 않습니다. JSZip CDN 로딩에는 인터넷 연결이 필요합니다.
- 정식 출시 전 실제 스프레드시트 원본 및 새 시즌 ZIP 교차 검증이 필요합니다.

## 라이선스 / 자산

기존 RKBO 저장소의 구단 로고 파일을 참조하며 사진은 사용자가 직접 올립니다. 외부 서비스는 파일 내용에 접근하지 않습니다.
