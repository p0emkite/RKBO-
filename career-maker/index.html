01 · 기록 데이터베이스

불러오는 중

HHRecord ZIP의 Results/Players/p_*.htm에서 선수별 역대 기록, LAST 3, ML Career를 자동 추출합니다.

최초 한 번 가져오면 이 브라우저에 선수 데이터가 보관됩니다.

누적 규칙 / 이용 안내

같은 선수 ID·시즌은 중복 추가하지 않고 새 기록으로 갱신합니다. 오래된 시즌 ZIP을 추가하더라도 가장 최근 시즌의 선수 소속팀 및 통산 요약을 보존합니다. 브라우저 DB는 기기별로 저장되므로 JSON 백업을 권장합니다. 서로 다른 리그의 HHRecord 파일은 같은 DB에 섞지 마세요.

선수의 실제 ML 시즌 수에 맞춰 표 높이가 자동 확장됩니다. A등급 FA는 노란색 글씨로 표시됩니다.

베타 출력 크기: 너비 1640px, 높이 시즌 수에 따라 자동 조절. 최종 규격은 템플릿 파일을 받으면 반영합니다.
